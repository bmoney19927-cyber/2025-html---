City Link

A city events app. Created to help solve the problem of organizing events.

About This Project

This project taught me how to work better as a team when it comes to creating anything. Even through the tough part of the group stages we got it done

Group project Teamwork Creativity

CityLink is an app/website that aims to connect people to events in their area. The software uses the customer’s location and interests to match the customer to events. Events have labels for details, like recommended/ minimum age to participate. Additionally, the software indicates if alcohol will be served and the entry cost. Customers can friend other users to view events friends are attending/attended. Friends can make friend groups, with each group providing additional recommendations based on each member. Also, with the ability to ban or blacklist individuals from using the app (if they were behaving inappropriately). The software will support event ratings, using a QR code posted past the entry in each event to verify the attendance of the user. Unlimited events can be posted using a premium account with the cost of the account being $12 a year. All customers can post 1 event for free without needing a premium account. The app will have 2 main modes with the first being near upcoming events in the user's area, which takes a broader approach and follows the user’s interests loosely. The other mode will allow the user to select a city/zip code, a distance, event categories, and date ranges. This allows the customer to find and plan larger events like conventions and music festivals. Looking forward to the future avenues for potential partnerships with already existing companies (Uber, Convention Centers, and Travel agencies, etc) .
